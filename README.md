# LLM Inference Optimization Quantization

This Python script demonstrates the core concept of LLM inference optimization through weight quantization. It simulates quantizing a simple neural network's weights to a lower precision and measures the resulting inference speedup.

## Language

`python`

## How to Run

Run this Python script using: python quantization_demo.py
Ensure you have PyTorch installed (`pip install torch`).
